<h3 id="프로젝트-기본-세팅-정리-frontend--backend">프로젝트 기본 세팅 정리 (Frontend / Backend)</h3>
<p>개인 프로젝트를 본격적으로 시작하기 전에<br />프론트엔드와 백엔드의 <strong>기본 개발 환경 세팅</strong>을 먼저 완료했다.</p>
<p>이번 세팅의 목표는<br />실제 실무에서 많이 사용하는 구조에 가깝게 프로젝트를 시작하는 것이었다.</p>
<hr />
<h3 id="backend-세팅">Backend 세팅</h3>
<ul>
<li>Java 17</li>
<li>Spring Boot</li>
<li>Spring MVC 기반 구조<ul>
<li>Controller / Service / Repository 계층 분리</li>
</ul>
</li>
<li>JSP<ul>
<li>관리자 페이지용 서버 사이드 렌더링</li>
</ul>
</li>
<li>Gradle</li>
<li>IntelliJ IDEA</li>
<li>Git / GitHub</li>
</ul>
<p>백엔드는<br />API 제공과 관리자 페이지를 담당하도록 구성했다.<br />관리자 화면은 JSP 기반으로 구현하고,<br />사용자 화면은 프론트엔드에서 분리해 관리하는 구조를 사용한다.</p>
<hr />
<h3 id="frontend-세팅">Frontend 세팅</h3>
<ul>
<li>React</li>
<li>Vite</li>
<li>TypeScript</li>
<li>Tailwind CSS v3</li>
<li>pnpm</li>
<li>Git / GitHub</li>
</ul>
<p>프론트엔드는 사용자 화면 전용으로 구성했다.<br />Tailwind CSS는 최신 버전 대신 안정화된 v3 버전을 사용했고,<br />기본 CSS 세팅 후 실제 화면에서 스타일이 정상 적용되는 것까지 확인했다.</p>
<hr />
<h3 id="github-레포지토리-구조">GitHub 레포지토리 구조</h3>
<p>프론트엔드와 백엔드는 <strong>각각 별도의 GitHub 레포지토리로 관리</strong>한다.</p>
<ul>
<li><p>Backend Repository  </p>
<ul>
<li>Spring Boot 서버</li>
<li>관리자 페이지(JSP)</li>
<li>API 로직 관리</li>
</ul>
</li>
<li><p>Frontend Repository  </p>
<ul>
<li>React + Vite 기반 사용자 화면</li>
<li>Tailwind CSS 스타일링</li>
</ul>
</li>
</ul>
<p>초기 세팅이 완료된 시점에서<br />각 레포지토리의 <code>main</code> 브랜치에 기본 세팅 커밋을 남겼다.</p>
<hr />
<h3 id="현재-상태">현재 상태</h3>
<ul>
<li>프론트엔드 / 백엔드 기본 환경 세팅 완료</li>
<li>Tailwind CSS 정상 적용 확인</li>
<li><code>.gitignore</code> 설정 완료</li>
<li>GitHub 레포 연동 및 초기 커밋 완료</li>
</ul>
<hr />
<h3 id="정리">정리</h3>
<p>이번 단계에서는 기능 구현보다<br />프로젝트 구조를 먼저 안정적으로 잡는 데 집중했다.</p>
<p>이제 다음 단계로는<br />기능 정의서를 작성하고,<br />관리자 페이지와 사용자 페이지의 핵심 기능을 하나씩 구현해 나갈 예정이다.</p>
