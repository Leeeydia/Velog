<h3 id="1-기능-목표">1. 기능 목표</h3>
<p>평소에 모동숲을 정말 좋아하는데,
내가 편지를 보내면 주민들이 답장을 보내주거나
가끔 엄마에게서 편지가 도착하는 기능을 특히 좋아한다.</p>
<p><img alt="" src="https://velog.velcdn.com/images/leeeydia/post/6183915e-8063-47b5-8653-5cdd77c3d178/image.png" /></p>
<p>그 따뜻한 감정을
내 프로젝트에도 꼭 담아보고 싶었다.</p>
<p>그래서 내가 좋아하는 그 “답장 기능”을
직접 구현해보기로 했다.</p>
<hr />
<p>사용자가 일기를 작성하면<br />AI가 해당 일기의 감정을 분석하여<br />&quot;선생님 모드&quot; 또는 &quot;부모님 모드&quot;에 맞는 답장을 생성하는 기능을 구현했다.</p>
<p>구조는 다음과 같다.</p>
<p>일기 1개 ↔ AI 답변 1개 (1:1 관계)</p>
<hr />

<h3 id="4-도메인-구조">4. 도메인 구조</h3>
<h4 id="aireplyvo">AiReplyVO</h4>
<p>DB와 매핑되는 객체</p>
<pre><code class="language-java">@Data
public class AiReplyVO {
    private Long id;
    private Long diaryId;
    private String replyType;
    private String replyContent;
    private LocalDateTime createdAt;
}</code></pre>
<hr />
<h4 id="aireplycreateresponse">AiReplyCreateResponse</h4>
<p>클라이언트에 내려주는 응답 DTO</p>
<pre><code class="language-java">@Builder
public class AiReplyCreateResponse {
    private Long id;
    private Long diaryId;
    private String reply;
    private LocalDateTime createdAt;
}</code></pre>

<h3 id="12-ai-답변-테스트">12. AI 답변 테스트</h3>
<p><img alt="테스트 로그인" src="https://velog.velcdn.com/images/leeeydia/post/524f2c11-c0b0-4f79-a101-025cde0c3d04/image.png" />
JWT 인증이 적용되어 있어 보안 처리가 되어 있기 때문에,
테스트를 진행할 때마다 <code>accessToken</code>을 헤더에 포함하여 로그인 인증을 해야 한다.
<img alt="일기 작성" src="https://velog.velcdn.com/images/leeeydia/post/d3f3a1a4-c127-4de1-a7e1-ef8c1a1aec27/image.png" />
로그인 후 일기를 작성하면 <code>memberId</code> 값을 기반으로 해당 사용자의 일기가 저장된다.
<img alt="AI 답변 첫시도 (상담사)" src="https://velog.velcdn.com/images/leeeydia/post/7365c2d0-94c5-4358-a440-d23fa5b21d24/image.png" />
AI 답변 첫 시도에서는 아직 부모님/선생님 모드가 적용되기 전이라
마치 ChatGPT와 직접 대화하는 듯한 상담사 느낌의 답변을 받았다.
<img alt="이미 존재하는 답변 1:1 관계" src="https://velog.velcdn.com/images/leeeydia/post/f45bd1ae-c454-46c9-a24f-c2e59f3e9763/image.png" />
또한, 하나의 일기에는 하나의 AI 답변만 생성되도록
1:1 관계로 설계하여 이미 답변이 존재하는 일기에는
추가로 답변을 받을 수 없도록 설정하였다.
<img alt="모드 선택 / reply_mode " src="https://velog.velcdn.com/images/leeeydia/post/eee55582-0a03-436a-a8e1-7462dfe55110/image.png" />
처음에는 매번 일기를 작성할 때마다 선생님/부모님 모드를 선택하도록 구현할까 고민했지만,
사용자가 미리 모드를 선택해두고 답변을 받는 구조가 더 깔끔하다고 판단하여
<code>reply_mode</code> 컬럼을 추가하였다.</p>
<p>해당 모드는 추후 마이페이지 또는 환경설정에서 변경할 수 있도록 구현할 예정이다.
<img alt="선생님모드 답장" src="https://velog.velcdn.com/images/leeeydia/post/b7b185d7-6dd8-4ed5-aa0c-fab6c994e0c0/image.png" />
선생님 모드로 답장을 받았을 때, AI가 자신을 지칭하는 주어가 없어 실제로 선생님에게 답장을 받는 느낌이 부족했다.<br />이를 개선하기 위해 프롬프트를 수정하여 반드시 자신을 지칭하는 주어가 포함되도록 보완했다.</p>
<p>또한, <code>created_at</code>이 null로 저장되는 이슈도 발생했는데, insert 시 null 값을 명시적으로 전달하면서 DB의 <code>DEFAULT CURRENT_TIMESTAMP</code>가 동작하지 않은 것이 원인이었다.<br />이에 insert 쿼리에서 해당 컬럼을 제거하여 DB가 자동으로 시간을 세팅하도록 수정함으로써 문제를 해결했다.</p>
<p><img alt="프롬프트" src="https://velog.velcdn.com/images/leeeydia/post/bf2e6a35-f826-4c93-9c97-8c122e60932c/image.png" />
프롬프트를 수정하여
반드시 자신을 지칭하는 주어(예: “선생님이”, “선생님은”)가 포함되도록 설정하였다.
<img alt="부모님 마지막 답장" src="https://velog.velcdn.com/images/leeeydia/post/19b00348-e9e5-492e-92b2-a4c0608ed096/image.png" />
마지막으로, 답장의 끝에 응원의 한 마디가 들어가면 좋을 것 같아
로그인 시 전달받은 {username} 값을 활용하여
닉네임을 포함한 개인화된 답장이 생성되도록 구현하였다.</p>
