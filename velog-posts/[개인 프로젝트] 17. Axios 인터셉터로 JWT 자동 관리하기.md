<p>프로젝트를 진행하면서<br />로그인 이후 API 요청마다 JWT 토큰을 직접 붙이는 작업이 반복되고 있었다.</p>
<p>이 작업을 매번 수동으로 처리하는 것은 실수 가능성도 높고,
코드도 지저분해질 수 있다.</p>
<p>그래서 Axios Interceptor를 활용해
JWT를 자동으로 관리하는 구조로 개선했다.</p>
<hr />
<h2 id="1️⃣-문제-상황">1️⃣ 문제 상황</h2>
<p>로그인 후 발급받은 accessToken을
모든 API 요청에 다음과 같이 붙여야 했다.</p>
<pre><code class="language-ts">headers: {
  Authorization: `Bearer ${accessToken}`
}</code></pre>
<p>문제는…</p>
<ul>
<li>매 API마다 반복 작성</li>
<li>토큰이 없을 경우 예외 처리 필요</li>
<li>401 발생 시 로그인 페이지 이동 처리 필요</li>
</ul>
<p>코드 중복 + 유지보수 부담이 생기기 시작했다.</p>
<hr />
<h2 id="2️⃣-해결-전략">2️⃣ 해결 전략</h2>
<h3 id="✔-공통-axios-인스턴스-생성">✔ 공통 axios 인스턴스 생성</h3>
<h3 id="✔-요청-인터셉터-→-jwt-자동-첨부">✔ 요청 인터셉터 → JWT 자동 첨부</h3>
<h3 id="✔-응답-인터셉터-→-401-자동-처리">✔ 응답 인터셉터 → 401 자동 처리</h3>
<hr />
<h2 id="3️⃣-공통-axios-인스턴스-분리">3️⃣ 공통 axios 인스턴스 분리</h2>
<pre><code>src/shared/api/axiosInstance.ts</code></pre><pre><code class="language-ts">import axios from &quot;axios&quot;;

const axiosInstance = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,
  withCredentials: true,
});

export default axiosInstance;</code></pre>
<hr />
<h2 id="4️⃣-request-interceptor--jwt-자동-첨부">4️⃣ Request Interceptor – JWT 자동 첨부</h2>
<pre><code class="language-ts">axiosInstance.interceptors.request.use((config) =&gt; {
  const token = localStorage.getItem(&quot;accessToken&quot;);

  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }

  return config;
});</code></pre>
<p>이제 API 호출할 때마다
Authorization 헤더를 따로 작성할 필요가 없다.</p>
<hr />
<h2 id="5️⃣-response-interceptor--401-자동-처리">5️⃣ Response Interceptor – 401 자동 처리</h2>
<pre><code class="language-ts">axiosInstance.interceptors.response.use(
  (response) =&gt; response,
  (error) =&gt; {
    if (error.response?.status === 401) {
      alert(&quot;로그인이 필요합니다.&quot;);
      localStorage.removeItem(&quot;accessToken&quot;);
      window.location.href = &quot;/login&quot;;
    }
    return Promise.reject(error);
  }
);</code></pre>
<p>토큰이 만료되거나 유효하지 않으면
자동으로 로그인 페이지로 이동하게 만들었다.</p>
<hr />
<h2 id="6️⃣-적용-후-api-사용-방식">6️⃣ 적용 후 API 사용 방식</h2>
<p>기존 방식</p>
<pre><code class="language-ts">axios.get(&quot;/api/diary&quot;, {
  headers: { Authorization: `Bearer ${token}` }
});</code></pre>
<p>개선 후</p>
<pre><code class="language-ts">axiosInstance.get(&quot;/api/diary&quot;);</code></pre>
<p>코드가 훨씬 깔끔해졌다.</p>
