<h3 id="ai가-답장해주는-음성-일기-서비스-프로젝트-기획-정리">AI가 답장해주는 음성 일기 서비스 프로젝트 기획 정리</h3>
<h4 id="1-프로젝트-개요">1. 프로젝트 개요</h4>
<p><strong>프로젝트 주제</strong><br />음성 기반 AI 일기 서비스</p>
<p><strong>핵심 기능</strong></p>
<ul>
<li>사용자가 하루를 말로 기록</li>
<li>음성을 텍스트로 변환</li>
<li>AI가 일기를 분석한 뒤 <strong>옛날 초등학생 일기처럼</strong> 변환된 텍스트 밑에 선생님/부모님/친구가 짧게 일기에 대한 답장을 작성</li>
</ul>
<hr />
<h4 id="2-필수-구현-기술-요구사항">2. 필수 구현 기술 (요구사항)</h4>

<li>이메일 인증</li>
<li>비밀번호 재설정</li>
</ul>

</ul>

<h4 id="3-사용-예정-api">3. 사용 예정 API</h4>
<p><strong>Naver Clova Speech API</strong></p>
<ul>
<li>실시간 음성 인식 지원</li>
<li>음성 데이터를 텍스트로 변환</li>
<li>멀티태스킹 환경에서도 사용 가능</li>
<li><a href="https://www.ncloud.com/v2/product/aiService/clovaSpeech">https://www.ncloud.com/v2/product/aiService/clovaSpeech</a></li>
</ul>
<p><strong>OpenAI API</strong></p>
<ul>
<li>일기 텍스트 분석</li>
<li>선생님/부모님/친구 버전의 답장 자동 생성</li>
</ul>
<p><strong>OpenWeather API</strong></p>
<ul>
<li>일기 작성 날짜 기준 날씨 정보 제공</li>
</ul>

<h4 id="4-핵심-아이디어">4. 핵심 아이디어</h4>
<h5 id="감정-선택-기반-일기-작성">감정 선택 기반 일기 작성</h5>
<ul>
<li><strong>메인 화면</strong>: &quot;오늘의 감정은?&quot; </li>
<li>사용자가 감정 선택 (기쁨/우울/화남 등)</li>
<li>선택한 감정에 따라 일기 작성 페이지로 이동</li>
</ul>
<h5 id="음성-기반-일기-작성">음성 기반 일기 작성</h5>
<ul>
<li>하루 일과를 음성으로 녹음</li>
<li>음성 → 텍스트 자동 변환</li>
<li>날짜별 일기 조회</li>
</ul>
<h5 id="ai-답장-생성">AI 답장 생성</h5>
<ul>
<li>일기 내용을 OpenAI에 전달</li>
<li>사용자가 선택한 답장 스타일로 생성<ul>
<li><strong>선생님 버전</strong>: 교육적이고 격려하는 톤</li>
<li><strong>부모님 버전</strong>: 따뜻하고 공감하는 톤</li>
<li><strong>친구 버전</strong>: 편안하고 친근한 톤 (도전 과제)</li>
</ul>
</li>
<li>일기 하단에 답장 텍스트 표시</li>
</ul>
<h5 id="해시태그">해시태그</h5>
<ul>
<li>키워드 기반 해시태그 자동 생성</li>
<li>사용자 직접 수정 가능</li>
</ul>
