<p>기술 스택: Spring Boot 3.2.x, Java 17, MyBatis, MySQL, JWT, WebClient(OpenAI)</p>
<p>이번 글에서는 지금까지 구현한 백엔드 기능을 전체 정리해본다.<br />단순 CRUD가 아니라 <strong>인증 → 권한 → 감정 분석 → AI 답장 → 마이페이지 → 게시판</strong>까지 흐름을 구성했다.</p>

<h2 id="1-회원auth-기능">1. 회원(Auth) 기능</h2>
<h3 id="✔-회원가입">✔ 회원가입</h3>
<ul>
<li>비밀번호 BCrypt 암호화</li>
<li>이메일 중복 검사</li>
<li>기본 reply_mode 설정</li>
</ul>
<h3 id="✔-로그인">✔ 로그인</h3>
<ul>
<li>JWT AccessToken 발급</li>
<li>응답 형태 통일 (ResultData)</li>
</ul>
<h3 id="✔-jwt-인증-구조">✔ JWT 인증 구조</h3>
<ul>
<li>Authorization: Bearer {accessToken}</li>
<li>AuthInterceptor에서 토큰 검증</li>
<li>request에 memberId 세팅</li>
<li>Controller에서 HttpServletRequest로 사용자 식별</li>
</ul>
<pre><code class="language-java">Long memberId = (Long) httpRequest.getAttribute(AuthInterceptor.USER_ID_ATTRIBUTE);</code></pre>
<p>👉 로그인 후 모든 기능은 JWT 기반 인증 필수</p>

<h2 id="2-일기diary-기능">2. 일기(Diary) 기능</h2>

<li>memberId 검증 로직 포함</li>
</ul>
<h3 id="✔-일기-수정-update">✔ 일기 수정 (Update)</h3>
<ul>
<li>작성자만 수정 가능</li>
</ul>
<h3 id="✔-일기-삭제-delete">✔ 일기 삭제 (Delete)</h3>
<ul>
<li>Soft Delete 방식 (is_deleted = true)</li>
</ul>
<hr />
<h3 id="✔-감정-기반-분류-기능">✔ 감정 기반 분류 기능</h3>
<ul>
<li>emotion 컬럼 기준으로 필터 조회 가능</li>
<li>사용자가 자신의 감정 기록을 확인할 수 있도록 설계</li>
</ul>
