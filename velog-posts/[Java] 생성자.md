<h2 id="생성자">생성자</h2>
<h4 id="생성자의-이름-규칙">생성자의 이름 규칙</h4>
<ul>
<li>자바에서는 객체의 생성과 동시에 인스턴스 변수를 원하는 값으로 초기화할 수 있는 생성자 라는 메소드를 제공한다.
자바에서 생성자의 이름은 해당 클래스의 이름과 같아야한다</li>
</ul>
<p>예를들어 Car 클래스의 생성자 이름은 Car 이다.</p>
<pre><code class="language-예시코드">class Car {
    String color;

    Car() { // 생성자
        color = &quot;red&quot;;
    }
}
</code></pre>
<ul>
<li>생성자는 void형으로 선언하지 않는다</li>
<li>new 키워드를 사용하여 객체를 생성할 때 자동으로 생성자가 호출된다.</li>
</ul>
<h4 id="기본생성자">기본생성자</h4>
<p>특별히 생성자를 정의하지 않고도 인스턴스를 생성할 수 있다 
  클래스 이름(){}</p>
<h4 id="매개변수가-있는-생성자">매개변수가 있는 생성자</h4>
<ol>
<li><p>생성자 this()
생성자에서 다른 생성자를 호출할 대 사용한다.
같은 클래스 안에 있는 생성자를 호출할 때 사용하며, 클래스 이름 대신 this를 사용한다
<strong>반드시 첫번째 줄에서만 사용이 가능하다.</strong></p>
</li>
<li><p>참조변수 this()
참조변수 this는 인스턴스 자신을 가리키는 용도이다. 
생성자와 인스턴스 메서드에서 사용 가능하며 클래스 메서드에서는 사용 불가능하다</p>
<p>지역변수와 인스턴스 변수(this, var)를 구별할 때 사용한다.</p>
</li>
</ol>
