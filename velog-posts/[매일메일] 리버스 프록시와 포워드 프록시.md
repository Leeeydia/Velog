<blockquote>
<p>리버스 프록시 (Reverse Proxy)</p>
</blockquote>
<ul>
<li><p>서버 측에 위치하여 외부에서 들어오는 클라이언트의 요청을 내부 서버로 전달하는 역할을 합니다.</p>
</li>
<li><p>로드 밸런싱 기능을 통해 다수의 백엔드 서버로 트래픽을 분산시켜 서버 과부하를 방지하고, 서비스의 고가용성을 유지할 수 있습니다.</p>
</li>
<li><p>이 외에도 외부에서 직접 백엔드 서버에 접근하지 못하게 서버를 보호 할 수 있으며 SSL 종료 기능을 통해 SSL/T:S 암호화를 리버스 프록시에서 처리함으로써 백엔드 서버의 부담을 줄이고. 중앙에서 인증서를 관리할 수 있다는 장점이 있습니다.</p>
</li>
</ul>
<blockquote>
<p>포워드 프록시 (Forward Proxy)</p>
</blockquote>
<ul>
<li>주로 클라이언트 측에 위치하여, 사용자가 인터넷에 접근할 때 중개자 역할을 합니다.</li>
</ul>
<p>예를 들어, 회사 내부 네트워크에서 근무하는 직원이 외부 웹사이트에 접속하려고 할 때, 포워드 프록시 서버를 통해 요청이 전달됩니다. 
이 과정에서 사용자의 실제 IP 주소는 숨겨지고, 프록시 서버의 IP 주소가 대신 사용됩니다.</p>
<p>이러한 익명성 제공 기능 덕분에 사용자의 실제 IP를 숨김으로써 개인정보 보호와 보안 측면에서 큰 장점을 제공합니다</p>
<ul>
<li>이 외에도 캐싱 (네트워크 성능 향상), 보안 강화 기능도 프록시의 중요한 역할 중 하나입니다.</li>
</ul>
